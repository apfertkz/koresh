# Кореш

Голосовой ассистент для Алисы: навык в Яндекс Диалогах, мозг на Claude, умный дом Яндекса, долгая память.
Сервис на Python (FastAPI), ставится на Railway одним шаблоном, настраивается мастером на странице `/setup`.

**Это не open source.** Код публичный только ради установки: клиенты ставят сервис из готового образа
`ghcr.io/apfertkz/koresh`, а образ собирается из этого репозитория. Использовать код и образ можно только
по договору с правообладателем, см. [LICENSE](LICENSE).

## Что внутри

- `main.py`, `brain.py`, `prompts.py`, `memory.py`, `iot.py`, `setupwiz.py` и др.: сам сервис
- `selftest.py`: ворота (282 проверки, без сети и ключей), запуск `python selftest.py`
- `Dockerfile`, `railway.json`, `template-variables.json`: сборка образа и переменные шаблона Railway
- `SETUP.md`: инструкция установки для клиента; `UPDATES.md`: как выпускаются и подтягиваются версии
- `.env.example`: все переменные окружения (значений секретов в репозитории нет и быть не должно)

## Образ и версии

CI (GitHub Actions) на каждый push в `main` и на каждый тег `v*` гоняет ворота и, если они зелёные, публикует
образ `ghcr.io/apfertkz/koresh`: `sha-<коммит>`, `latest` (только `main`), `stable` и `<версия>` (только тег `v*`).
Клиенты сидят на `stable`.
